## Lazy loading (both tasks rely on it)

- A library is imported only inside the code path that needs it: `await import('marked')`,
  `await import('dompurify')`, `await import('highlight.js/lib/core')`, so Vite emits each as its own chunk.
- highlight.js languages come from `import.meta.glob('/node_modules/highlight.js/es/languages/*.js')` with the
  `*.js.js` duplicates excluded: one chunk per language, loaded by name. A filename maps to a language through
  `hljs.getLanguage`/aliases plus a small extension table (`Dockerfile`, `Makefile`, `.tf`, `.jq`, `.yml` …).
- A test asserts the built `kd.js` does not statically import marked, DOMPurify or highlight.js.

## Task A — `kd-code`, `kd-markdown`, `feed` (owner: agent A)

Files: `src/kd/elements/code.ts`, `src/kd/elements/markdown.ts`, `src/kd/highlight.ts` (the language loader and
filename table), `src/kd/feed.ts`; tests in `test/kd/`. Agent A also adds these to `src/kd/index.ts`.

- `kd-code` per the spec: `text`, `language` | `filename`, `lines` (default true), `wrap`, `highlight`
  (`"3,7-9"` or number[]), `start`. Token classes styled in the shadow root from `--kd-*` (map hljs scopes:
  keyword, string, number, comment, title/function, attr, built_in, type, meta, tag, name, deletion/addition…).
  Above a size threshold (measure; ~200 KB or ~5k lines) render plain text with line numbers. Copy button.
- `kd-markdown`: `markdown`, `base: {links, images}`, attribute `src`. GFM on. Sanitize with DOMPurify (no
  scripts, no event handlers, no `javascript:` URLs; keep `class` on code fences for the language). Code fences
  become `kd-code` (language from the fence). Heading anchors (`id` slugs), external links open in a new tab with
  `rel="noopener"`. Relative `href`/`src` rewritten against `base`. Typography in the shadow root matching
  `kd.css` (tables, blockquote, lists, task lists, hr, images max-width).
- `feed(context, map)`: `applyTheme(context.element, context.grafana.theme)`; for each `selector: props` set the
  properties on every matching element under `context.element` (`Object.assign`), idempotent. Returns the
  elements. Also `variable(context, name)` (read via `context.grafana.replaceVariables`, '' when unset).

## Task B — `kd-files`, `kd-file`, providers, `github` (owner: agent B)

Files: `src/kd/files/` (`types.ts`, `static.ts`, `explorer.ts` = `kd-files`, `file.ts` = `kd-file`),
`src/github/` (`tree.ts`, `urls.ts`, `index.ts`); tests in `test/kd/files*.test.ts` and `test/github/`. Agent B
does NOT edit `src/kd/index.ts` (agent A does); export from `src/kd/files/index.ts` and report.

- Provider contract (`types.ts`): `Entry {path, name?, type: 'file'|'dir', size?, modified?, href?,
  stats?: Record<string, number>, cells?: Record<string, Cell>, partial?: boolean}` (`partial` = a folder the
  provider could not list); `Provider { list(path): Promise<Entry[]>; read?(path): Promise<{text?: string;
  blob?: Blob; type?: string; size?: number}>; capabilities?: {read?, write?, rename?} }`.
- `staticProvider(entries)`: builds folders from a flat list (implicit parent dirs), sizes and every numeric
  stat rolled up per folder.
- `kd-files`: `provider` | `entries`, `columns` (`[{key, label, kind: 'size'|'stat'|'cell'|'modified'}]`, default
  name + size), `selected`, attributes `variable`, `key`, `filter` (show the filter box). Breadcrumbs + `..`,
  folders first, sort by any column, filter (current folder, then recursive when typed), keyboard (arrows, Enter,
  Backspace), selection highlight, `partial` folders marked, events `navigate` / `select` `{path, entry}`. On
  select with `variable`, write the Grafana variable with the scene helpers (replace history, like today's
  `locationService.partial(…, true)`); `selected` drives the highlight and opens its folder. Folder kept in
  sessionStorage under `key` (try/catch), else the selected file's folder, else root.
- `kd-file`: `path`, `text` | `blob`, `type`, `size`, `links: [{text, href, icon}]`, `provider` (+ `path` → reads
  it). Header: path breadcrumb, size, links. Body by type: markdown → `kd-markdown` (with `base` property passed
  through), text/code → `kd-code` (filename → language), image → `<img>` (object URL or `src`), else a summary.
  Binary detection when no type: NUL bytes or high non-text ratio.
- `github`: `treeEntries(rows)` from the Repo dashboard's file-tree jq output (`{oid, path, type, size}`; see
  `tabs/files/src/file-tree.A.jq`), `blobUrl(repo, ref, path)`, `rawUrl(repo, ref, path)`, `readmeBase(repo,
  ref)` (`{links, images}`), `codeServerUrl(host, repo, path)` (host is an argument), and `pathHash(path)` —
  the exact hash in `tabs/files/src/file-tree.helpers.js` / the jq `def h` in `variables/state.yaml`, with test
  vectors computed from both.
